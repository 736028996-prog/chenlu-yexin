# 晨露小径

叶馨 的像素风个人主页样本。职业写成 AI 产品经理。页面是田园小农场：木屋、菜地、昼夜和一张不会寄出的纸条。

画面用 Canvas、CSS 和 SVG 自己画，直角像素，没有使用任何游戏的素材、角色或地名。经历、项目和联系方式都是占位，发布前请换成自己的，并删掉「示例」「虚构」。

技术上只有 HTML、CSS 和 JavaScript，没有框架，也没有后端。双击 `index.html` 就能打开。

## 在本地看

直接打开：

1. 进入这个文件夹
2. 双击 `index.html`

或者起一个本地静态服务（复制草稿到剪贴板时，用这种方式更稳）：

```bash
python3 -m http.server 47321
```

浏览器打开 `http://127.0.0.1:47321`。

## 改什么

| 想改 | 去哪里 |
| --- | --- |
| 名字、介绍、项目、联络说明 | `index.html` 里的中文 |
| 公开真实联系方式 | `index.html` 里 `#contact-lines` 的注释，加上 `<li>`，只写文字，不要写假邮箱 |
| 颜色 | `css/styles.css` 顶部的变量 |
| 菜名、量词、开局长势 | `js/farm.js` 顶部的 `CROPS` 和 `START` |
| 远处的房子、树、鸡 | `js/scene.js` 顶部的 `DAY` / `NIGHT`，以及 `draw` 里的坐标 |
| 像素人 | 替换 `assets/yexin-character.jpg` |
| 昼夜如何记住、弹层、复制草稿 | `js/main.js` |

菜地进度存在这台浏览器的 `localStorage`（键名 `chenlu-garden-v1`）。换浏览器或清站点数据会回到示例开局。

## 页面里有什么

- 一幅会动的田园：云、烟、鸡、猫。夜晚有月亮、星星和萤火虫。
- 右上角可以切换白天 / 夜晚。选择会记住；如果还没选过，会先跟着系统的深色设置。
- 六块菜地：选种子、播种、浇水、收获。方向键可以在地块之间移动。
- 三张示例项目卡片，点开是手记弹层。Esc 或点外面可关闭。
- 联络区只复制草稿，不会发送，也没有假链接。

## 键盘和减少动画

- 第一个 Tab 是「跳到正文」。
- 菜单、昼夜、种子、菜地、弹层关闭按钮都可以用键盘操作。
- 系统开了「减少动态效果」时，云和鸡会停住，成熟菜地也不再闪动。
